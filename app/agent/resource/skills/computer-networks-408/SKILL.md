# 408 计算机网络题库

> 题库目录：`/exam-408/计算机网络/`。题目按章节组织，文件名包含年份、题号和知识点。

## 1. 目录约定

```text
/exam-408/
├── 00-索引.md              # 章节 → 题目清单，先读它建立全局印象
└── 计算机网络/
    ├── 01-体系结构/
    ├── 02-物理层/
    ├── 03-数据链路层/
    ├── 04-网络层/
    ├── 05-传输层/
    ├── 06-应用层/
    └── 07-综合/            # 跨章节综合题
```

文件名格式：`<年份>-<题号>-<知识点>.md`，例如：

```text
05-传输层/2018-39-UDP分用.md
04-网络层/2019-39-子网广播地址.md
07-综合/2019-47-设备选型与定向广播.md
```

- 题号 `01-40` 是单项选择题，`41-47` 是综合应用题。
- 一道题只放在一个章节里，以主要考点为准；跨章节的综合题放在 `07-综合`。

## 2. 检索流程

1. **看全局**：`materials_read("/exam-408/00-索引.md")`，确认各章节题量和题目清单。
2. **按知识点**：
   - `materials_ls("/exam-408/计算机网络")` 看章节；
   - `materials_ls("/exam-408/计算机网络/05-传输层")` 看该章全部题目，文件名自带知识点；
   - 只 `materials_read` 命中的那一题。
3. **按关键词**：`materials_grep("拥塞窗口", path="/exam-408/计算机网络/05-传输层")`。**必须带 `path`**，不要在整个资料库上 grep。
4. **按年份题号**：在对应章节 `ls` 找 `<年份>-<题号>` 前缀；不确定章节时先查 `00-索引.md`。
5. **按题型**：综合应用题题号是 41-47，文件名前缀带年份，可在各章节中按题号筛选。
6. **没有命中**：说明题库暂未收录，不要编造年份和题号；改用教材和考纲自拟题，并明确说明是自拟题。

## 3. 出题规则

- 题目文件通常同时包含题干、选项、答案和解析；出题时只把题干和选项交给 `quiz_student`，答案放进 `correct_option` 或 `reference_answer`。
- 调用 `quiz_student` 前的正文不要泄露答案、正确选项或关键解题步骤。
- 学生提交后再使用解析，按「考点 → 答案 → 解析 → 易错点 → 变式」讲解。
- 一次只出一题。
