# 408 计算机网络题库

> 题库目录：`/exam-408/`。这里放真题、模拟题和按知识点整理的练习。

## 1. 目录约定

```text
/exam-408/
├── 00-索引.md          # 题库说明和索引
├── 选择题/
└── 综合题/
```

每道题一个 Markdown 文件，文件名包含题号、题型和知识点，例如：

```text
选择题/01-性能指标-时延带宽积.md
综合题/04-网络层-子网划分与路由聚合.md
```

## 2. 检索流程

1. 先 `materials_read("/exam-408/00-索引.md")`，看题库范围和索引；
2. 用 `materials_ls("/exam-408")` 逐层确认目录；
3. 已知知识点或关键词时，用 `materials_grep("拥塞控制", path="/exam-408")` 定位；
4. 用 `materials_read` 只读命中的那一道题；
5. 目录不存在或没有命中时，说明题库暂未收录，改用教材和考纲自拟题，不要编造年份和题号。

## 3. 出题规则

- 题目文件通常同时包含题干、选项、答案和解析；出题时只把题干和选项交给 `quiz_student`，答案放进 `correct_option` 或 `reference_answer`。
- 调用 `quiz_student` 前的正文不要泄露答案、正确选项或关键解题步骤。
- 学生提交后再使用解析，按「考点 → 答案 → 解析 → 易错点 → 变式」讲解。
- 一次只出一题。
