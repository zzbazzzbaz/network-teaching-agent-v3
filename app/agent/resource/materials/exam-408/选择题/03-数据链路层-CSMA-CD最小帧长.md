# CSMA/CD 最小帧长

- 题型：单选
- 知识点：数据链路层、CSMA/CD、最小帧长
- 来源：自拟练习题（非真题）

## 题目

某以太网的数据传输速率为 100 Mbit/s，网络最大单程传播时延为 2.56 μs。为使 CSMA/CD 能可靠检测冲突，最小帧长约为（ ）。

## 选项

A. 64 bit
B. 512 bit
C. 1024 bit
D. 128 bit

## 答案

B

## 解析

CSMA/CD 要求发送方在发送完一帧之前就能检测到冲突。最坏情况下，冲突信号需要经过一个往返传播时延 2τ 才能回到发送方。

最小帧长 = 2τ × 数据传输速率 = 2 × 2.56×10^-6 × 100×10^6 = 512 bit。

512 bit 等于 64 字节，这也是传统以太网最小帧长 64 字节的来源。

常见错误：只乘单程传播时延 τ；或者把 100 Mbit/s 写成 100 bit/s。
