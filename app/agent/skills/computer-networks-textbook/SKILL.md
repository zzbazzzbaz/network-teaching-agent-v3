# 计算机网络教材

> 教材：计算机网络（第8版），谢希仁。

这里只有教材事实：正文、页码、图注。出题和题库操作走 `quiz_student` / `get_question` 工具，进度和误解记在 `/memory`。

## 1. 资料位置

教材已索引到课程知识库（system 共享），不提供文件读取。所有教材事实通过 `search_knowledge` 获取，不要尝试读文件、执行 grep 或猜测原文。如果 `search_knowledge` 不可用，直接说明教材检索暂不可用，不要编造。

## 2. 检索流程

1. 用小节标题、术语或英文缩写作为 query，一次问一个明确的问题；
2. 命中后看 `source` 和正文第一行的页码；不确定就换同义词、英文缩写或小节号再查；
3. 只取回答需要的一两块，按“章节 + 小节 + 教材第 N-M 页”作答；
4. 没有命中就说明教材未覆盖，不要编造原文或页码。

命中结果形如：

```text
[1] (source: 5.5-TCP报文段的首部格式-p225-229-03.md)
【第5章 5.5 TCP报文段的首部格式 | 教材第225-229页】

TCP 报文段首部的前 20 个字节是固定的……
```

`source` 里的 `p225-229` 和正文第一行的 `教材第225-229页` 是同一信息，引用时用后者。

## 3. 页码与引用

- 页码来自命中块第一行 `【… | 教材第A-B页】`，不要引用目录或推测页码；
- 源数据只有小节级页码范围，不要编造单页页码；只有检索结果明确给出单页时才写单页；
- 区间引用：`见第 5 章 5.5，教材第 225-229 页。`

教材没有覆盖时，直接说明这一点，不要编造原文或页码。
