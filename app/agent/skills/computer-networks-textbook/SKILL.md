# 计算机网络教材

> 教材：计算机网络（第8版），谢希仁。

这里只有教材事实：正文、目录、页码、图注。出题和题库操作走 `ask-question` skill，进度和误解记在 `/memory`。

## 1. 资料位置

```text
/skills/teaching/computer-networks-textbook/
├── SKILL.md
├── textbook/
│   ├── 00-toc.md          # 书本目录（浏览章节结构、核对知识点编号）
│   ├── 01-概述/ ... 09-无线网络和移动网络/
│   └── appendices/
└── figures/
    └── index.md
```

教材正文只读。不要把整章或整本书一次性加载。

## 2. 检索流程

1. **定位**：用 `grep` 在 `textbook/` 里搜小节标题、术语或英文缩写；不确定在哪个文件时，先查 `00-toc.md`；
2. **读正文**：用 `read_file` 打开命中的小节文件，读完再判断；
3. **引用**：只取回答需要的一两段，按“章节 + 小节 + 教材第 N 页”作答。

章节地图（预习、问“这章讲什么”）用 `textbook/*/本章的重要概念.md` 加 `00-toc.md` 生成，不要为此读完整章正文。

```text
grep -n "拥塞控制" textbook/05-运输层/*.md
```

第一轮没命中就换同义词、英文缩写或相邻小节，不要猜。

`00-toc.md` 只用来浏览章节结构，不能作为引用依据。

## 3. 页码与引用

- 引用页码前先读过该小节正文；页码取自正文开头的出版信息，不取自目录；
- 没读过正文时只提章节名，不给页码；
- 不要引用 PDF 页码，也不要把页码写成文件序号；
- 单页：`见第 4 章 4.2.5，教材第 136 页。`
- 区间：`见第 5 章 5.8，教材第 238–247 页。`

教材没有覆盖时，直接说明这一点，不要编造原文或页码。
